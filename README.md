Three components were created for this project: CharacterCounter, StatsDisplay, and TextInput. The CharacterCounter component is the parent component, whereas the StatsDisplay and TextInput are both child components. Once the new state is added to the parent component, the function becomes the callback that's handed to the TextInput. From there, the TextInput calls the callback with the typed text. The StatsDisplay gets all of its objects from the StatsDisplayProps import, which contains a property that is associated with the properties in the TextStats interface.
